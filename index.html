🔑 API 키 발급 방법 (일부 앱에만 필요)

골프일기·Talk Spark는 여러분 본인의 API 키가 있어야 동작합니다. 키는 앱을 연 기기에만 저장되고, AI 요청도 기기에서 직접 보내므로 저희 서버나 다른 사람에게 노출되지 않아요.

Claude API 키 — 골프일기·Talk Spark

  1. platform.claude.com 에 가입합니다.
  2. 결제 수단을 등록하거나 크레딧을 충전합니다.
  3. API Keys 메뉴에서 키(sk-ant-…)를 새로 만듭니다.
  4. 골프일기 설정에 그 키를 붙여넣습니다.

⚠️ Claude API는 사용량 기반 유료 서비스입니다. 사용료는 본인 부담이에요.
